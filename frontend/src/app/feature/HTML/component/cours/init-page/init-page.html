Explication des lignes

!< doctype html >

Cette ligne dit à l'ordinateur que le type ce fichier sera du HTMl

< html lang="en" >

Indique le début de la page html. L'attribut lang définit la langue utilisé dans le site pour le référencement. Pour un site en français, remplacer en par fr.

< head >

Cette balise englobe tous les imports de fichier ou données autres

< meta >

Cette balise sert à déterminer les métadonnées : le type de caractère, le type d'affichage possible, les méta pour le SEO ou l'ia ....

< title >

Sera le titre de la page

< body >

À l'interrieur de cette balise il y aura tout le corps de la page

< / html >

Cette balise indique la fin de la page html. Au-delà le code ne sera pas lu
