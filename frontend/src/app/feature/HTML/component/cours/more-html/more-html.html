Résumé On a appris précédement comment stucturer une page basique et pour le moment sans aucun style.
Il est donc interessant pour vous d'apprendre maintenant le style avec CSS.
De plus si vous vouler pouvoir rendre dynamique votre page, il faudra apprendre le JavaScript. Cela vous permettra aussi de découvrir de nouvelles balises pour faire des formulaire ou utiliser des boutons. Ressources pour encore plus de HTML

Documentation officielle : MDN

Youtubeur : Graven et Grafikart

Cours gratuit (nécessite une inscription sans engagement) : openclassrooms

J'ai choisi ses ressources par expérience professionnelles.
MDN est LA référence pour toutes les informations sur HTML, CSS, JS.
Les deux youtubeur proposent des cours rapides en faisant un mini projet.
Openclassroom met à disposition les cours qui incluent, un projet et des vidéos ainsi que des mini quizz pour vérifier que le chapitre est compris.

Comment s'éxercer ? Le meilleur moyen de s'éxercer c'est de faire. Voici une liste de quelques projets:
  • Fiche pour se présenter
  • Blog sur son apprentissage
  • Exposé sur un thème que l'on apprécie
  • Fiche de solution et découverte de GTA VI
Quand on débute, faire des pages sur des sujets que l'on aime, est beaucoup plus agréable et la motivation ne sera qu'augmenter.
