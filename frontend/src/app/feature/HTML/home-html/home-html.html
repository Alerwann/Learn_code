HTML

À quoi sert HTML ?

HTML est le squelette du site. C'est grâce à ça que l'on structure les informations qui vont s'afficher.

Ce n'est pas un langage de programmation à proprement parler mais un langage de balisage. Cela signifie qu'il se base sur des balises qu'on ouvre et ferme.

Même si c'est utilisé depuis le début du web, il reste toujours d'actualité. Sans comprendre ce langage, il est impossible de créer un site même avec les framework courant REACT et Angular.

Où trouver la documentation ?
MDN est la référence pour la documentation de HTML. Toutes les balises sont répertoriées et il permet de tester directement pour mieux comprendre.
Comment l'apprendre ?

L'apprentissage de l'html est peu fun sans le CSS. En effet le html pur affiche du text noir sur fond blanc.

Il est plus interessant est donc de l'apprendre en même temps que le css.

Il est évident que la pratique reste la meilleure méthode pour retenir.

 Les règles indispensables

Pour la plus part des balises retient : "Quand tu l'ouvres, tu la fermes!"

Le référencement sur google actuellement, se base sur les pages HTML. Il faut donc en prendre soin.

S'il y a un grand nombre de balises c'est qu'elles sont toutes utiles! N'utilises pas que des 'div' mais soit précis!
